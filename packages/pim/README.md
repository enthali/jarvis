# Jarvis PIM

Jarvis Personal Information Manager — categories and tasks.

Adds a **Categories** view to the Jarvis sidebar and a custom Task Editor for `.jarvis-task` files. Category management is available when Outlook integration is enabled in `enthali.jarvis-core`.

## Features

- **Categories** view — manage Outlook categories (requires `jarvis.pim.showCategories` and `jarvis.outlook.enabled`)
- **Task Editor** — custom editor for `.jarvis-task` files

## Configuration

Enable the Categories view with `jarvis.pim.showCategories` and `jarvis.outlook.enabled`.

## Requirements

- `enthali.jarvis-core` (Jarvis Core) must be installed.
