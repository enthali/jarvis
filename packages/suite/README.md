# Jarvis Suite

Extension pack that installs all Jarvis extensions in one click.

## Included Extensions

| Extension | Description |
|-----------|-------------|
| **Jarvis** (`enthali.jarvis`) | Core — sessions, messaging, reminders, heartbeat, engine |
| **Jarvis PIM** (`enthali.jarvis-pim`) | Personal Information Manager — projects, events, categories, tasks |
| **Jarvis Recorder** (`enthali.jarvis-recorder`) | Session recording, whisper pipeline, and transcript notifications |
| **Jarvis MCP** (`enthali.jarvis-mcp`) | MCP Server — exposes all registered Jarvis tools over MCP HTTP transport |

Each extension can also be installed independently.
