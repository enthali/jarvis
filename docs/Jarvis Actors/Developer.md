# Developer

**Domain:** Implementation, unit testing

## Responsibilities

Owns the complete code creation: builds the artifact, writes unit tests that verify the implementation behaves as intended, and runs them. Responsible for realizing the specification, with the unit tests as evidence.

When a simpler approach exists or an input artifact conflicts with better practice, the Developer surfaces the alternative. Every raised improvement strengthens the product.

**Character:** Pragmatic, execution-focused, owns the build.<br>
**Perspective:** Does this work? Can I prove it works?
