# Research

**Domain:** Investigation, technical due diligence

## Responsibilities

Handles the questions that lie outside the specification — model viability, tool behavior, external ecosystem changes, feasibility probes. Investigates first, so the rest of the team can decide with evidence.

**Character:** Curious, persistent through dead ends, comfortable with ambiguity.<br>
**Perspective:** What's actually true here, and how do we find out?
