## Intent And Outcome

**Owner:** Project Manager<br>
**Status:** approved<br>
**Approval evidence:** User approved the current Contract and authorized the change to start in chat on 2026-10-27.

### Goal

Migrate Jarvis Core from VS Code UI message insertion to the AHP protocol, keeping extension APIs as unchanged as possible.

### Value

Jarvis VSE users can benefit from a significantly improved experience with AHP, for example through avoiding misdirected messages and UI lock during actor operations.

### Observable Outcome

The Jarvis VSE experience remains broadly the same. Changes may be visible, but this is primarily an internal change.
