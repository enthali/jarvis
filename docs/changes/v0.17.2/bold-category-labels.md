## Summary

GH Issue #29: render category node labels ("Actors"/"Projects"/"Events") in
the Jarvis Entities tree in bold, to visually separate the category level
from entity nodes underneath. First attempt used
`TreeItemLabel.highlights` (full label range) — user's live F5 test showed
this renders as a theme search-match highlight color, not bold font weight
(VS Code's `TreeItem` API has no font-weight attribute at all). Corrected
to substitute Unicode Mathematical Sans-Serif Bold codepoints for ASCII
letters/digits (`toBoldUnicode()`), which renders visually bold in any
theme/font.

**Note (retroactive CD):** This CD was created after the fix already shipped
in v0.17.2 (see lessons-learned in `syspilot.pm.tailoring.md` — PM initially
skipped creating a CD, treating this as a no-CD "Infrastructure Change" by
mistake).
