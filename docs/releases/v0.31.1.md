## Objective And Scope

**Owner:** Project Manager<br>
**Status:** approved<br>
**Approval evidence:** User approved the Release scope, user-guided Operation Mode and Release start in chat on 2026-10-24.

### Objective

Publish a patch containing the fix for conflicting CLI tool references and completing removal of the already-deprecated Jarvis Suite and obsolete Change scaffolder. This release adds no new user capability; Release confirms the version under its Version artifact.

### Included Changes

1. `namespace-jarvis-language-model-tools` - package-prefixed Language Model Tool references and descriptions for Core, PIM, Kanban and Syspilot; squash-integrated at `98c38a8`; Change Contract closed.
2. `extension-readiness-and-suite-retirement` - PIM/Syspilot readiness disclosures, complete Suite retirement, and removal of the legacy Change generator; squash-integrated at `f3aed83`; Change Contract closed.

### Known Limitations

- Jarvis PIM remains experimental and does not include email triage; that capability remains in an externally maintained skill outside the Jarvis PIM release.
- Jarvis Syspilot is marked `EXPERIMENTAL — DO NOT USE` because the upcoming syspilot 0.10 release is expected to break compatibility.
- Existing Suite installations are not removed and no longer receive Suite updates. Historical GitHub Release assets and the Marketplace extension ID are retained; the Suite Marketplace listing is unpublished.
- Previously authored prompts using the unprefixed `#task` or `#category` references must use the package-prefixed tool references instead.
