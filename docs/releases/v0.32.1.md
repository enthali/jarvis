## Objective And Scope

**Owner:** Project Manager<br>
**Status:** approved

### Objective

Proposed patch release 0.32.1 for two closed fixes and retirement of the deprecated experimental jarvis-syspilot extension. The Release actor must confirm the SemVer classification: the extension was already marked deprecated / do not use / experimental, but its package removal must still be assessed against the release rule for breaking changes. The User unpublished the Marketplace listing on 2026-11-16; Release verifies the status during preflight.

### Included Changes

1. `actor-instructions-opt-out` — integrated at `4c32046d`; closed at `2a00d6d8`. Actor instructions are provisioned by default; users can opt out.
2. `kanban-tool-validation` — integrated at `4132d5cf`; closed at `385f3879`. Corrects Kanban ID/labels validation and handler tests.
3. `retire-jarvis-syspilot` — integrated at `1999480f`; closed at `745a7802`. Removes the deprecated extension and active integration. The User unpublished its Marketplace listing on 2026-11-16; Release verifies that status before publication.

### Known Limitations

- Existing installations of `enthali.jarvis-syspilot` are not automatically updated or uninstalled by Jarvis; users must uninstall them manually.
- The extension listing is currently Unpublished, so it is unavailable for download. Marketplace documentation says unpublished extensions remain publicly discoverable via an existing API and their statistics are preserved.
- Version 0.32.1 is a proposal only; Release owns the final SemVer decision.

**Owner:** Release<br>
**Status:** pending | passed | failed
