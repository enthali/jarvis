## Objective And Scope

**Owner:** Project Manager<br>
**Status:** approved

### Objective

Pre-release 0.35.1 (`Channel: pre-release`, tag `v0.35.1-pre`) migrates `.github/workflows/release.yml` from `VSCE_PAT` to VS Code Marketplace OIDC Trusted Publishing (`@vscode/vsce` `4.1.1`), adds the tag-driven `pre-release` channel (`vX.Y.Z-pre`, `--pre-release` on package and publish for all six Marketplace extensions, `prerelease: true` on GitHub Release) together with pre-release-aware Release Notes URL lookup in `releaseNotes.ts` and user opt-in instructions in Getting Started, splits `.github/workflows/docs.yml` into `build` and `deploy` jobs on Node-24 actions, fixes retired `enthali.jarvis` references in `packages/mcp/README.md`, and streamlines all 68 User Stories to three personas without leaked internal API names. Publishing on the `pre-release` channel verifies OIDC Trusted Publishing, Marketplace Pre-Release channel isolation, and the two-job GitHub Pages workflow live without pushing an infrastructure-focused release to stable users. The version number is confirmed as `0.35.1` (plain `0.35.1` in manifests, tagged `v0.35.1-pre`) by explicit User decision (2026-11-26 02:30 CET): the pre-release channel and `-pre` release-notes 404 lookup are release-infrastructure and link-fix changes rather than a user-facing product feature, keeping `0.36.0` reserved for the next feature release.

1. `streamline-user-story-personas-and-acs` — integrated at `74e67463`; closed at `8b4d44b6`.
