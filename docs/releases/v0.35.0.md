## Objective And Scope

**Owner:** Project Manager<br>
**Status:** approved

### Objective

Release 0.35.0 ships read-only Kanban swimlanes, the custom-editor Refresh button, and declared-field Kanban query filters; adds Flow chord-node tooltips, time-lens handle clamping/keyboard commit, and requeue notifications plus Heartbeat startup/resume scanner validation; drops the unused `sql.js` WebAssembly bundle from Core; exposes `outputVar` in the `jarvis_registerJob` schema; records verified macOS support; and brings the entire Jarvis specification baseline to zero `deprecated` and zero `draft`/`open` Needs. The version number is Release's SemVer decision; the Project Manager's candidate is 0.35.0 because the release delivers user-visible Kanban and Flow features.

### Included Changes

1. `kanban-swimlanes-and-filters` — integrated at `08d59dfc`; closed at `a642b7c1`. Kanban custom-editor Refresh button (GH #55), read-only collapsible swimlanes by `single_select` field or `Labels` with deduplicated column totals (swimlanes portion of GH #47), and declared-field filtering in `jarvis_listKanbanItems` / `jarvis_listKanbanFilterValues` (K72, K17, K14).
2. `retire-legacy-session-lookup` — integrated at `5e39dca7`; closed at `c54b451f`. Removes dead pre-AHP `state.vscdb`/WSL2 session lookup and drops `sql.js` / `sql-wasm.wasm` from Core (K75); aligns `jarvis_createActor` tool description with `jarvis.actors.folder` (K64).
3. `purge-deprecated-and-stale-specs` — integrated at `865d97e0`; closed at `e5bbdd6f`. Forbids `deprecated` in the ontology and Needs check, deletes 11 retired Needs and `us_olk.rst`, and aligns `jarvis.outlook.enabled` in PIM runtime messaging and specifications (K25, K70, K71, K45, K56).
4. `heartbeat-and-reminder-cleanup` — integrated at `e4f1b65c`; closed at `57eaf04c`. Exposes `outputVar` in `jarvis_registerJob` schema and Core docs (K53), removes stale `jarvis.heartbeatConfigFile` and `registerDualTool` claims (K54, K28), and corrects Core Reminder delivery documentation (K29).
5. `kanban-cleanup` — integrated at `b0c376c0`; closed at `f00ff5bf`. Documents the Kanban `archive` board convention in `SKILL.md` and the Kanban guide (K16), aligns plain-text filter and `fields: {}` specs (K78, K63), and tests all nine real Kanban tool handlers for owner resolution (K62, K68).
6. `sidebar-and-spec-cleanup` — integrated at `c9818300`; closed at `7d90c827`. Extracts dedicated Messages and Heartbeat tree stories (`US_MSG_TREE`, `US_AUT_HEARTBEATTREE`) and Core guide coverage (K33, K34, K36), anchors the kernel no-identity-section rule (K59), and verifies all contributed commands across all six packages are registered (K07).
7. `settle-draft-specifications` — integrated at `b9c19c3e`; closed at `a6b3e235`. Audits and settles all remaining `draft` Needs to `implemented` (K55, zero `draft`/`open` enforced by test), implements Flow chord node tooltips, time-lens handle clamping/keyboard commit, requeue host notifications, and Heartbeat startup/interval/resume scanner validation, and marks macOS as verified (2026-11-24) in Core documentation.

### Known Limitations

- Windows (Windows Sandbox, 2026-11-19) and macOS (User live run, 2026-11-24) Agent Host operation are verified; WSL and SSH remain unverified.
- In a Codespace, the User exercised the installed discovery prototype `a21fba6` (discovery, messaging, and opening Actor chats worked); Dev Tunnels and the Agents window connected to a Codespace remain outside validation.
- Kanban swimlanes are read-only tab-session state; drag-and-drop write-back and actor delta notifications remain open in GH #47 (Phase 2).
- Flow chord tooltip and time-lens clamping/keyboard changes were verified against a fake DOM in Vitest (`flow-webview-chord.test.ts`), not manually exercised in a live webview overnight (delegated by the User, 2026-11-24).
- The live run of `ac_heartbeat.rst` with `pwsh` or `powershell` remains deferred (covered by system and `executeJob` wiring tests).
