## Objective And Scope

**Owner:** Project Manager<br>
**Status:** approved

### Objective

Release 0.33.0 includes five closed changes already integrated on development, including changed defaults and retirement of the deprecated experimental jarvis-syspilot extension. The User approved including the two additional Categories changes and agreed to 0.33.0 on 2026-11-16. The User unpublished the Marketplace listing on 2026-11-16; Release verifies the status during preflight.

### Included Changes

1. `pim-categories-view-default-off` — integrated at `ada1b574`; closed. Hides the Categories view by default.
2. `outlook-categories-setting` — integrated at `3e0139ed`; closed at `cbdffd34`. Moves Categories configuration under Outlook and makes it opt-in.
3. `actor-instructions-opt-out` — integrated at `4c32046d`; closed at `2a00d6d8`. Actor instructions are provisioned by default; users can opt out.
4. `kanban-tool-validation` — integrated at `4132d5cf`; closed at `385f3879`. Corrects Kanban ID/labels validation and handler tests.
5. `retire-jarvis-syspilot` — integrated at `1999480f`; closed at `745a7802`. Removes the deprecated extension and active integration. The User unpublished its Marketplace listing on 2026-11-16; Release verifies that status before publication.

### Known Limitations

- Existing installations of `enthali.jarvis-syspilot` are not automatically updated or uninstalled by Jarvis; users must uninstall them manually.
- The extension listing is currently Unpublished, so it is unavailable for download. Marketplace documentation says unpublished extensions remain publicly discoverable via an existing API and their statistics are preserved.
